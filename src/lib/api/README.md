# `src/lib/api` — the typed client for `getpack-api`

Nothing here is hand-written except the clients. Response and request types come from
`schema.d.ts`, generated by `pnpm gen:api` from the backend's OpenAPI contract and
committed; CI fails if the committed copy drifts (ADR-0006).

| File               | What it is                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `schema.d.ts`      | generated from `contract/openapi.json` — **never edit, never hand-write a response type**                                                |
| `schema.seed.d.ts` | generated from `mocks/seed-openapi.json` — the temporary auth surface, deleted when getpack-api B1.3 ships                               |
| `types.ts`         | the one place both are named. Removing the seed is one line here                                                                         |
| `client.ts`        | the shared middleware: bearer token, `Accept-Language`, request id, CSRF, `Idempotency-Key`, and problem details → a thrown `ApiError`   |
| `server.ts`        | `serverApi(zone)` for Server Components: `API_INTERNAL_URL`, the zone cookie's token, and a guard against calling another zone's surface |
| `browser.ts`       | `browserApi()` for Client Components: base URL `/bff`, no token — the browser cannot read one                                            |
| `problem.ts`       | `ApiError` and `applyProblemToForm`                                                                                                      |
| `query-keys.ts`    | the key factory, so an invalidation cannot miss a cache by spelling                                                                      |

## Working with the contract

```sh
pnpm gen:api          # regenerate from the vendored contract
pnpm gen:api:check    # the CI gate: fails if a committed output is stale or hand-edited
pnpm gen:api --adopt  # pull a newer contract from API_CONTRACT_SOURCE and re-pin the lock
```

`contract/openapi.json` is a vendored copy of what `getpack-api` has published, pinned by
sha256 in `contract.lock.json`. It is vendored so the drift gate is reproducible offline —
CI has no sibling checkout of the backend. Moving to a newer contract is `--adopt`, which
rewrites the vendored copy and the lock together, so it appears in a PR diff rather than
happening as a side effect of a build. The resulting type errors are the change list.

If an endpoint you need does not exist yet, write it into `docs/contract-requests.md` and
use an MSW mock marked `// CONTRACT-REQUEST` — never invent a shape silently. A screen is
not done while a `CONTRACT-REQUEST` mock is still serving it.
