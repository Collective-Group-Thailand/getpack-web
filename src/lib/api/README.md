# `src/lib/api` — the typed client for `packio-api`

Nothing here is hand-written except the clients. Response and request types come from
`schema.d.ts`, generated by `pnpm gen:api` from the backend's OpenAPI contract and
committed; CI fails if the committed copy drifts (ADR-0006).

Planned in F1:

- `schema.d.ts` (generated — never edit, never hand-write a response type)
- `serverApi(zone)` for Server Components: `API_INTERNAL_URL`, bearer token from the zone
  cookie, `Accept-Language`
- `browserApi` for Client Components: base URL `/bff`, same generated types
- query keys and error mapping

If an endpoint you need does not exist yet, write it into `docs/contract-requests.md` and
use an MSW mock marked `// CONTRACT-REQUEST` — never invent a shape silently.
