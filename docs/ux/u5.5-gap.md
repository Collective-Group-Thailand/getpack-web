# U5.5 — getpack Assistant (flagged) — gap analysis (getpack-web, 2026-10-06)

`docs/prompts/U5-ux-excellence.md` §U5.5, against `main` after U5.1–U5.7 and contract **v0.41.0**, which
carries getpack-api's U5.B5 (`v0.37.0`): sessions, turns, seven tools, guardrails, limits, logs and
the evaluation harness (D-304–D-306). **D-218 stands: the assistant is off at launch**; ADR-0012
(model / vendor / data terms) is *Proposed*, and `assistant.enabled` cannot be switched on outside
local until a provider is named and an evaluation run clears (D-306). Post-launch (D-219).

So this session builds the **web side behind two locks**: a build flag (`NEXT_PUBLIC_ASSISTANT`,
off — no assistant code ships without it) and the API's own switch (a session refused with
`assistant.disabled` / `assistant.not_configured` shows the way to a person instead).

Status: **met** · **partial** · **missing** · **API gap** (contract request + mock) · **API scope** (getpack-api decided otherwise; recorded, not built).
