## สิ่งที่ต้องแก้ก่อนเริ่ม (blocker)

1. **ลูกค้าเข้าสู่ระบบไม่ได้:**
   - getpack-web ตอนนี้ชี้ไปที่ `https://uat-api.getpack.co`
   - ขอ OTP แล้วได้ `503 provider.unavailable` ("ผู้ให้บริการภายนอกไม่ตอบสนอง") เพราะ UAT ไม่ได้อยู่ในโหมด `INTEGRATIONS_MODE=fake` รหัส `000000` จึงใช้ไม่ได้
   - **ทางแก้ที่ 1:** ตั้ง UAT เป็นโหมด fake สำหรับเบอร์ `080000xxxx`
   - **ทางแก้ที่ 2:** รัน getpack-api บนเครื่อง (`:3000`) ในโหมด fake แล้วชี้ `API_INTERNAL_URL` มาที่ API บนเครื่อง
2. **ข้อมูลที่ยังไม่มีใน UAT:** ต้องสร้างผ่าน API ก่อนจับ
   - ตัวแทนขาย C13 ที่มีลูกค้าและใบแจ้งยอด
   - คำสั่งซื้อที่มีพรูฟให้อนุมัติ
   - payment ทดสอบ 1 รายการ (สำหรับ A21, D6)
   - ลิงก์แชร์แบบ 1 ลิงก์
   - ลิงก์ใบเสนอราคาที่หมดอายุ 1 ลิงก์
3. **getpack-web:** ควรรันแบบ `next build && next start` เพื่อให้จับภาพได้เร็วและครบ

## หลังจับภาพ

- **ตรวจภาพ:** คัดภาพที่เป็นหน้าเข้าสู่ระบบหรือหน้า error ที่ไม่ได้ตั้งใจออก
- **โฟลเดอร์สำหรับอัปโหลด:** สร้าง `_shots/customer-upload/<กลุ่ม>` ให้เจ้าของลากเข้าโปรเจกต์ Stitch ของแต่ละกลุ่ม (A, B+C, D)
- **รายงาน:** แจ้งเจ้าของทุกครั้งที่จับครบ 1 กลุ่ม พร้อมจำนวนหน้า หน้าที่ล้นจอ และหน้าที่จับไม่ได้ พร้อมเหตุผล
